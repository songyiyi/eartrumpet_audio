01

要回答的三个问题

软件侧已经全部就绪——设计方案、参考实现、固件（与 Python 逐位一致、可为 Cortex-M7 编译）、实时调参界面。但这一切都建立在一个未经验证的假设上：这条路真的能出好声音。

本阶段的唯一目的就是验证它。做板子只是手段。

问题怎么算回答了影响
概念是否成立有没有某组参数能让处理声与自然自听"融"起来决定项目是否继续
最佳佩戴位置乳突／下颌／喉部三者中哪个骨导信号最干净、中频最完整决定头戴机械结构
参数落点调参界面上三个滑块的最终位置成为固件默认值
最大的单点风险

皮肤表面测到的振动，与耳蜗实际感受到的骨导声之间，隔着一个无法直接测量的颅骨传递函数。能逼近到什么程度只有实验能回答。所以这一步必须在投入任何产品级硬件开发之前完成。

03

接线

Nucleo-144 的 Morpho 排针（CN11／CN12）引出了 STM32 的全部信号，所以引脚不会不够，问题只在于避开板载外设占用的脚。

信号两块传感器板Nucleo 引脚备注
3V3J1.1 / J2.13V3板上直接取
GNDJ1.2 / J2.2GND多接两根，别只接一根
PDM_CLKJ1.3 / J2.3PC2DFSDM1_CKOUT，串 100 Ω 靠 Nucleo 侧
PDM_DATAJ1.4 / J2.4PC7DFSDM1_DATIN3，串 100 Ω 靠 Nucleo 侧

两块板并联接同一组 CLK 与 DATA——这正是"两颗传感器共用一根数据线、靠时钟极性分左右"的接法，也是硬件级采样同步的来源。

两条容易忽略的

引脚以 CubeMX 为准。PC2 支持 CKOUT、PC7 支持 DATIN3 是查证过的，但 Nucleo-H743ZI2 上以太网占用了不少引脚（PC1 就是以太网 MDC）。CubeMX 会直接标出冲突并给可用备选，比查复用表快得多。

台面调试先用 10–20 cm 短线，不要一上来就接一米线缆。先把信号完整性这个变量排除掉；采集通了再换长线，那时出问题就知道是线的锅。

04

分步流程

原则：每一步只引入一个新变量。这样出问题时能立刻定位，而不是面对一堆可能性。

  1. 步骤 0

    到货检查（动手焊之前）

    先确认 V2S200D 的引脚编号已到手。这是唯一的阻塞项——手册没拿到就别贴片。6-TLGA 焊上去没有任何补救余地。获取途径：knowles.com/V2S，或向经销商索取 User Guide。

    收到 PCB 后检查三件事：气导板声孔是否存在且约 ⌀0.8 mm、孔周围有没有被阻焊或铺铜堵住、焊盘是不是阻焊定义（SMD）类型。

    验证点 — 三项全对。错一项就要重新打样，早发现早止损。
  2. 步骤 1

    只测开发板，不接任何传感器

    这一步把"时钟对不对"和"传感器好不好"分开。跳过它的话，接上传感器不工作时你会误判成器件坏了。

    1. 烧个流水灯，确认工具链与下载器通
    2. CubeMX 配好 DFSDM，生成代码
    3. 测 PC2（DFSDM_CKOUT）
    验证点 — 3.072 MHz 方波，占空比 48–52%（手册对 ≥2.9 MHz 有此硬要求）。没有仪器时的测法见第 05 节。
  3. 步骤 2

    贴装传感器板

    钢网刷锡膏 → 放件 → 热风或加热台回流。回流次数 ≤3 次，峰值 260 °C。

    焊完用万用表查：VDD 与 GND 不短路、四条网络各自通断正常。焊点目视检查不了，这是唯一的电气检查手段。

    验证点 — 无短路，四网络通。
  4. 步骤 3

    先接一颗，不要两颗一起

    先接气导麦（IM69D130），因为它最容易验证——对着说话就该有反应。采到数据后存成 WAV 听一遍，确认无误再接骨导那颗。

    验证点 — PDM_DATA 安静时是规律的 0101 交替，说话时密度明显变化。
  5. 步骤 4

    双通道与敲击测试

    两颗都接上后，用手指轻敲骨导传感器，看哪个声道有信号。不要靠推理判断 SELECT 高低对应左还是右——直接测。

    方案约定 左＝骨导、右＝气导（与评估套件一致）。若实测相反，改固件比改硬件容易。

    验证点 — 两声道内容不同；敲骨导时只有一个声道跳。
  6. 步骤 5

    录素材（这才是真正的实验）

    戴上传感器同时录制两路，三个佩戴位置各录一组。每次换位置都用医用胶带或发带压紧，保持恒压贴合——接触松紧对信号影响极大，这也正是要试的东西。

    验证点 — 三个位置 × 四类素材，共 12 段录音，见第 07 节清单。
  7. 步骤 6

    调参与判定

    python tools/tune_gui.py 你的录音.wav

    戴封闭式耳机，边说话边听处理后的信号。方法与判据见第 07 节。

    验证点 — 第 01 节那三个问题各有一个明确答案。
05

没有示波器怎么办

其实这个场景下示波器不是最优工具——你要看的是数字信号，不是波形细节。三条替代路径，按性价比排序。

首选 · USB 逻辑分析仪，¥30–60

最常见的 8 通道 24 MHz 款（Saleae 兼容克隆）就够。3.072 MHz 需要至少 8 MHz 采样才看得清，24 MHz 绰绰有余。配免费的 PulseView（sigrok），能看时钟波形、量占空比、看数据活动，还有 I²S／PDM 解码插件。

对数字调试它比示波器更好用，且便宜十倍以上。如果只买一件工具，买这个。

次选 · 万用表（免费，但真能用）

用直流电压档测方波，读到的是平均值：

测点正常读数异常说明
PDM_CLK≈1.65 V3.3 V＝卡在高电平；0 V＝没输出
PDM_DATA≈1.65 V0 V 或 3.3 V＝传感器没在驱动
传感器 VDD3.3 V明显偏低＝供电或短路问题

1.65 V 是 3.3 V 的一半，因为时钟占空比 50%、PDM 静音时是 0101 交替。这个方法区分不了频率对不对，但能区分活着还是死了——早期调试八成的问题就是后者。

第三 · 把 STM32 自己当测量仪器

你手上已经有一块 480 MHz 的仪器。两个用法：

  • 测时钟频率：把 PC2 用杜邦线接到另一个引脚，配一个定时器做外部计数，数一秒的边沿数——就是一台频率计
  • 测信号活性：capture.py --monitor 的 RMS／峰值／DC 读数
串口诊断输出示例

CH0 RMS −62.3 峰值 −48.1 DC +0.0004　　CH1 RMS −48.7 峰值 −31.2 DC −0.0011

由 tools/capture.py --monitor 每秒刷新。静音时 DC 应接近 0、RMS 很低；DC 接近 ±1 表示数据线卡死或悬空，RMS 为零表示传感器没输出。敲一下骨导传感器看哪个通道的 RMS 跳——步骤 4 的敲击测试完全可以靠这个完成，不需要任何仪器。

诊断刻意在电脑侧算：固件已经把原始比特流经 DFSDM 消费掉，拿不到"1 的密度"；而且文本诊断与二进制音频流共用一个串口会互相破坏。固件只用红灯指示曾经丢块。

06

预期现象与故障速查

这些现象是正常的，别误判
现象为什么正常
骨导通道信号明显很弱Knowles 明确说明它需要补约 +20 dB 才能对齐普通麦克风电平。这是设计预期，不是焊坏了
骨导几乎没有高频±3 dB 带宽只有 4 kHz，且 2.5 kHz 以上原厂就说明需要摆位优化配合软件均衡
骨导有低频隆隆声呼吸与皮肤摩擦，处理链里的 80 Hz 高通就是为它准备的
这些是真问题
现象先查什么
完全没有数据时钟有没有输出 → 供电是否 3.3 V → SELECT 是否悬空
两个声道内容一样两颗的 SELECT 接成了同一电平，必须一高一低
有信号但底噪很大100 nF 是否紧靠 VDD 引脚 → 地是否完整 → 是否用了开关电源供电
间歇性杂音、时好时坏先查供电电压是不是 1.8 V。见下方说明
低频响应很差气导板声孔是否被锡膏堵住或密封不良
必须用 3.3 V，不能用 1.8 V

两颗传感器都支持 1.62／1.65 V 起，很容易顺手选 1.8 V。那样会出事：IM69D130 的输出高电平 VOH 最低为 0.7 × VDD，1.8 V 时只有 1.26 V，而 STM32H7 的 3.3 V I/O 逻辑高门限约 2.31 V——够不到。

这类故障不会干脆地不工作，而是表现为间歇性杂音，极难定位。两颗都跑 3.3 V（V2S200D 上限 3.3 V，IM69D130 上限 3.6 V）。

MEMS 工艺禁忌

不能超声清洗、不能水洗。清洗液进入声腔会永久损坏振膜，而且损坏后表现为"能工作但音质差"，几乎无法判断。若板厂默认工序含清洗，下单时必须特别注明；手工焊后也别用洗板水冲。

调参方法

最容易毁掉判断的坑

响的那个总是听起来更好。混合比从 0 推到 1 时输出峰值会涨 3–4 dB（骨导路有 +20 dB 归一化增益）。不补偿的话，你会误以为"骨导多一点更好听"，其实只是听到了更响。

每次改完混合比，先用输出电平滑块把峰值拉回原读数，再判断音色。A／B 旁通同理。

调参顺序（参数之间有交互，乱调会陷入死循环）：

  1. 先关限幅、设好电平——限幅会压掉动态干扰音色判断。让峰值落在 −6 到 −3 dBFS
  2. 定混合比——最粗、影响最大。从 0.5 开始（Békésy 的等贡献结论），先扫出"明显太薄"和"明显太闷"两个边界，再二分逼近
  3. 调音色——混合比定了之后再细修 EQ 曲线
  4. 回头微调混合比——音色变了最佳混合比会漂移，迭代两三轮收敛
判据不是"好不好听"

而是"像不像你自己听到的自己"——这两件事经常打架，最像的往往并不最好听。

具体做法：戴封闭式耳机，边说话边听处理后的信号。参数对了，处理声会和你的自然自听"融"在一起，感觉只是变响了；不对则能听到明显的"两个人在说话"的分离感或梳状染色。那个分离感消失的位置就是答案。

这个判据比"回忆刚才的声音"可靠得多——人对音色的听觉记忆只有几秒，且极不稳定。
