01

先看三条数据手册修正

查阅原厂手册后，有三条信息与之前的方案不一致，都影响设计。

修正一 · V2S200D 带宽是 4 kHz，不是 10 kHz

之前引用 Syntiant 页面的「Bandwidth 10 kHz」，但 Knowles 自家的产品概览写明 ±3 dB 带宽为 4 kHz。10 kHz 多半指采样带宽而非有效响应。

好消息是这反而印证了现有设计：骨导路低通设在 3 kHz 恰好落在传感器有效范围内，没有浪费也没有越界。Knowles 还指出 2.5 kHz 以上「需要摆位优化配合软件均衡」，且传感器谐振在 5 kHz 附近——低通到 3 kHz 正好避开谐振。

修正二 · IM69D130 是底部声孔

手册第 13 节明确要求：PCB 上必须在器件正下方开声孔，且孔径要大于麦克风自身的声孔。麦克风声孔为 ⌀0.6 mm，推荐 PCB 开孔 ⌀0.8 mm。焊盘为阻焊定义（SMD）类型，焊环需完整以保证气密——漏气会毁掉低频响应。

这一条画错就要重新打样，务必在布局阶段就留好孔。

修正三 · SNR 随时钟下降有了确切数字

之前说「别用低功耗模式」是定性判断，现在有手册数据支撑：

3.072 MHz → 69 dB(A)　　2.4 MHz → 68 dB　　1.536 MHz → 66 dB　　768 kHz → 64 dB

电流从 980 µA 降到 300 µA，代价是 5 dB 信噪比。演出设备不该做这个交换。另注意 ≥2.9 MHz 时时钟占空比要求收紧到 48–52%，配置 STM32 时钟树时要留意。

02

板 A · 骨导传感器（乳突）

V2S200D 是振动传感器：它必须刚性压在皮肤上才能工作，PCB 本身就是机械传导路径的一部分。板子松动或悬空会直接毁掉信号，机械固定比电路更值得花时间。这块板不要开任何孔。

V2S200D 引脚编号必须自行查证

我无法从公开渠道取到 V2S200D 的引脚编号表（Mouser 的用户指南下载持续失败）。上图按功能名标注，建立立创 EDA 符号时必须从 Knowles 官方手册填入编号。引脚编号靠推测是绝对不可接受的——它是 6-TLGA 底部端子封装，焊上去之后没有任何补救余地。

获取途径：knowles.com/V2S，或向经销商索取 V2S200D User Guide。

03

板 B · 气导麦克风（嘴角）

与板 A 的唯一电气差异是 SELECT 接到 3V3 而非 GND——两颗传感器必须取相反设置，才能各占时钟的一个边沿、共用同一根数据线。C3 的 100nF 是手册明确要求「尽量靠近 VDD 引脚以保证最佳 SNR」，不是可选项。

04

主板侧接口

Infineon 手册的立体声应用电路（图 10）建议在 CLK 与 DATA 上串约 100 Ω 端接电阻以抑制振铃与过冲。电阻放在主板端（时钟驱动源）。

主板侧元件
位号值位置与作用
R1100 Ω串在 PDM_CLK 上，紧靠 STM32 引脚。抑制反射与边沿过冲
R2100 Ω串在 PDM_DATA 上，紧靠 STM32 引脚

U3LDO 3.3 V给传感器单独供电，不要与数字电源共用开关电源
为什么必须是 3.3 V 而不是 1.8 V

两颗传感器都支持 1.62/1.65 V 起，很容易顺手选 1.8 V。那样会出事：IM69D130 的输出高电平 VOH 最低为 0.7 × VDD，1.8 V 时只有 1.26 V，而 STM32H7 的 3.3 V I/O 逻辑高门限约 2.31 V——够不到。

这类故障不会干脆地不工作，而是表现为间歇性杂音，极难定位。两颗都跑 3.3 V（V2S200D 上限 3.3 V，IM69D130 上限 3.6 V），省掉电平转换。

注意 DATA 线上的负载电容手册限制为 ≤200 pF，一米线缆加端接电阻要留意别超。

一米线上跑 3 MHz 时钟

这是本设计最大的信号完整性风险。措施：屏蔽线、时钟与数据各自双绞、驱动端串端接电阻。手册要求时钟上升/下降时间 ≤13 ns，而长线会让边沿劣化。

退路：若实测不可接受，把 PDM→PCM 转换挪到头端，线上只跑低速 I²S。但那会让头戴组件变复杂，先按简单方案试，别提前优化。

哪一路落在左声道

SELECT 的高低决定传感器占用时钟的哪个边沿，也就决定它在 DFSDM 里是「左」还是「右」。不要靠推理确定——上电后用手指轻敲骨导传感器，看哪个通道有信号，据此配置固件即可。设计方案里约定 左 = 骨导、右 = 气导（与评估套件一致），若实测相反，改固件比改硬件容易。

MEMS 器件的工艺禁忌

MEMS 麦克风与振动传感器不能超声清洗、不能水洗——清洗液进入声腔会永久损坏振膜。若板厂默认工序含清洗，下单时必须特别注明。手工焊后也不要用洗板水冲。

07

立创 EDA 专业版操作要点

这两颗器件立创商城大概率没有现成库（我未能确认库存），所以符号与封装都要自建。这也意味着即使我生成可导入的工程文件，你仍要自己画封装——所以本文档给的是网表和工艺参数，那才是真正省时间的部分。

建符号

  • 器件 → 新建 → 符号。V2S200D 建 5 个引脚（VDD/GND/CLOCK/DATA/SELECT），编号从官方手册填
  • IM69D130 按本文第 03 节的编号直接填：1 DATA、2 VDD、3 CLOCK、4 SELECT、5 GND

建封装（这一步最关键）

  • 焊盘设为阻焊定义（SMD），不是常见的铜箔定义（NSMD）
  • IM69D130 正下方放一个 ⌀0.8 mm 的非金属化孔作声孔，孔周焊环保持完整
  • 顶层与底层在声孔周围不要铺铜也不要开窗，避免锡膏流入堵孔
  • 丝印标出 Pin 1 方向——底部端子器件贴反了完全看不出来

布局

  • C1/C3 放在 VDD 焊盘同层、2 mm 以内
  • PDM_CLK 与 PDM_DATA 尽量短、尽量不换层；若必须换层，就近打地过孔伴随
  • 板 A（骨导）机械刚度优先：加固定螺孔或加厚板材，让整块板能被压紧在皮肤上

建议的推进方式

第一版只做这两块传感器小板，配现成的 Nucleo-H743ZI 开发板（DFSDM 引脚已引出），杜邦线连起来验证 PDM 采集、两路同步、声孔与机械耦合。确认无误后再画腰包主板。

理由是两部分风险来源不同：传感器板的风险在声学与机械，主板在电源与模拟输出。混在一起打样，出问题时分不清是哪一半，而一次打样周期就是一两周。
